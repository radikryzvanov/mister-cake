# Mr.Cake

Сайт кофейни Mr.Cake (Ульяновск, ул. Хваткова, 1В).

Обычный статический сайт: файл `index.html` и папка `assets` с фото. Сборка не нужна.

## Как обновить цены и блюда
В конце `index.html`, в блоке `<script>`, находятся списки:
- `LUNCHES` — горячие обеды и мясо по-чешски
- `SALADS` — салаты
- `DESSERTS` — торты и десерты
- `pizzas` — пицца

У каждого блюда есть `name` (название), `price` (цена в рублях, `null` показывает «Цена в чате») и `photo` (путь к фото).
Ссылка на MAX: переменная `MAX_URL` в том же блоке.

## Публикация
Подключён к Vercel: каждый коммит в `main` обновляет сайт.
